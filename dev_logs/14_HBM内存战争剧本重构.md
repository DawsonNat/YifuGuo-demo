# 开发日志 14：HBM 内存战争剧本重构与多阵营设计

**记录时间**：2026-05-23
**目标**：记录根据最新需求进行的剧本彻底重构。废弃原有的“Dropout”剧情，改为围绕“HBM 显存涨价”展开的多地点、多阵营、6 Agent 混战的宏大叙事。

---

## 1. 剧本重构核心动机
*   **紧跟时事**：以当前 AI 行业 HBM 显存供不应求、价格暴涨为背景，极大地增强了 Demo 的真实感和代入感。
*   **充分压榨引擎能力**：
    *   **多地点移动 (`MoveEffect`)**：引入了前台、私人会议室、主谈判室三个地点，完美展示了引擎的地点切换与记忆隔离能力。
    *   **多阵营对抗**：从单挑变成了“英伟达防守方” vs “存储巨头进攻方”的 6 人大混战，充分展示了 Multi-Agent 引擎处理复杂群聊和立场博弈的强大算力。

## 2. 角色与阵营分布 (6 个实体 Agent)
*   **英伟达阵营**：
    *   Agent 1：接待前台（位于前台，负责信息向上传递）。
    *   Agent 2：Jensen Hwang（黄仁勋，被逼宫的 CEO）。
    *   Agent 3：Tech VP（技术副总裁，负责底层逻辑推演）。
*   **存储巨头阵营**：
    *   Agent 4：SK Hynix CEO（傲慢的霸主）。
    *   Agent 5：Micron CEO（见风使舵的商人）。
    *   Agent 6：Samsung CEO（老谋深算的笑面虎）。

## 3. 四个 Phase 的动态路由设计
*   **Phase 1 (Turn 1-4) 前台破局**：玩家在前台说服 Agent 1，Agent 1 通过 RDC 私聊会议室里的 Jensen。触发路由后，Jensen 移动到私人会议室。
*   **Phase 2 (Turn 5-12) 私密审查**：玩家在私人会议室向 Jensen 汇报。Jensen 通过 RDC 私聊会议室里的 Tech VP 求证。触发路由后，Jensen 带着玩家杀回主会议室。
*   **Phase 3 (Turn 13-20) 舌战群儒**：6 方混战。玩家+英伟达阵营 vs 三大存储巨头。玩家需要用技术逻辑击溃巨头们的质疑。触发路由后，三大巨头被“请”到前台（离开会议室）。
*   **Phase 4 (Turn 21-25) 胜利果实**：Jensen 抛出终极 Offer（加入公司 vs 投资 1 亿美金），根据玩家选择和 Trust 数值生成结局。

## 4. 技术落地评估
经过对 `agent_world` 底层源码的再次审查，此剧本**完全可行**：
*   前台的“传话”和 Jensen 的“求证”都可以通过 `send_message` 工具（RDC 通道）完美实现。
*   地点的切换可以通过在路由节点注入 `MoveEffect` 完美实现。
*   Phase 3 的混战可以直接利用同地点的 `FaceToFaceBus` 零延迟广播机制实现。

这套新剧本不仅故事性拉满，更是将 `agent_world` 引擎的“多通道通信”、“多地点管理”和“动态状态机”三大核心卖点展现得淋漓尽致！

## 5. 故事一句话梗概与核心卖点 (Logline)
*   **一句话梗概**：在 AI 算力短缺、HBM 显存价格暴涨的生死关头，一个 19 岁的辍学生带着革命性的压缩算法闯入英伟达总部，在黄仁勋的私人会议室里通过了技术审查，并最终与英伟达高管并肩作战，在谈判桌上舌战三大存储巨头，成功打赢了这场显存价格保卫战。
*   **核心体验标签**：#商战博弈 #硬核技术流 #爽文反转 #多阵营混战

## 6. 补充设计：阵营内部的群聊机制 (Group Chat)
*   **忽略的功能点补齐**：之前的设计只关注了跨房间的单对单私聊 (RDC)，忽略了引擎强大的**群聊机制 (`GroupMessageBus`)**。
*   **新机制应用**：
    *   **英伟达高管群**：创建一个 `group_id: 100` 的群聊（包含 Jensen 和 Tech VP）。在 Phase 3 混战时，Jensen 可以通过群聊向 VP 发送战术指令，而不需要单点私聊。
    *   **存储巨头联盟群**：创建一个 `group_id: 200` 的群聊（包含海力士、美光、三星 CEO）。在 Phase 3 混战时，三大巨头可以在群里“对口供”，商量怎么联合绞杀玩家。
*   **UX 表现**：在前端的“上帝视角”监控区，不仅会显示 `[私聊]`，还会显示 `[群聊: 存储巨头联盟] 海力士 -> 群: "别信这小子，我们咬死 30% 涨价不松口！"`。这将极大地丰富阵营对抗的戏剧张力。
